Education Board API

Unified REST interface for Bangladesh education board exam results and institution data.

Base URL: http://localhost:3000
GET / POST /api/get-result
Fetch student individual exam result and grades
Request Parameters
Field Type Requirement Description
exam string Required
Examination program
jsc ssc hsc dibs
board string Required
Education Board code
barisal chittagong comilla dhaka dinajpur jessore madrasah mymensingh rajshahi sylhet tec
year number Required Four-digit passing year (e.g. 2025). Range: 1996 – present.
roll number Required Candidate 6-digit exam roll number.
reg number Required Candidate 10-digit registration number.
maxCaptchaRetry number Optional Maximum auto-solve retry attempts for verified captcha. Clamped between 10 and 500 (Default: 50).
Supported Content-Types: For GET requests, provide parameters in the URL query string. For POST requests, application/json, application/x-www-form-urlencoded, and multipart/form-data bodies are all supported.
cURL (GET) 
curl "http://localhost:3000/api/get-result?exam=ssc&board=jessore&year=2025&roll=617381&reg=2213489227"
cURL (POST) 
curl -X POST "http://localhost:3000/api/get-result" \
  -H "Content-Type: application/json" \
  -d '{
    "exam": "ssc",
    "board": "jessore",
    "year": 2025,
    "roll": 617381,
    "reg": 2213489227
  }'

GET /api/get-institutions
Lookup schools and colleges under specific boards
Query Parameters
Field Type Requirement Description
board string Required Education Board code (e.g. dhaka, jessore, chittagong).
exam string Required Examination type: jsc, ssc, hsc, dibs.
year number Optional Passing year. If omitted, server will automatically scan backwards from the current year to find the latest published list.
type string Optional
Output structure shape:
flat Flat array of institution objects with EIIN, code, name, zilla, thana nested (Default) Hierarchical tree grouped by zilla → thana → [institutions]
Output Note: Flat lists output items with shape { eiin, code, name, zilla, thana }. Nested output provides fast geographical grouping without extra client-side manipulation.
cURL (Nested Output - Default) 
curl "http://localhost:3000/api/get-institutions?board=jessore&exam=ssc&year=2025"
cURL (Flat Output) 
curl "http://localhost:3000/api/get-institutions?board=jessore&exam=ssc&year=2025&type=flat"
